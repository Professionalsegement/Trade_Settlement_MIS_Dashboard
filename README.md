# Trade Settlement MIS Dashboard

## Overview

The Trade Settlement MIS Dashboard is a Power BI project developed to monitor trade settlement activities across counterparties and asset classes. The dashboard provides visibility into settlement status, trade volumes, break reasons, and transaction amounts to support operational reporting and decision-making.

---

## Objective

The objective of this dashboard is to:

- Monitor settled and failed trades
- Identify key settlement break reasons
- Track transaction amounts by counterparty
- Analyze trade distribution across asset classes
- Provide a consolidated operational MIS view

---

## Tools Used

- Power BI Desktop
- Microsoft Excel

---

## Dashboard Components

### Settlement Status
Tracks the number of:

- Settled Trades
- Failed Trades

### Break Reason Analysis
Shows settlement exceptions caused by:

- SSI Mismatch
- Insufficient Funds
- Unmatched Instructions

### Counterparty Analysis
Displays total transaction amount (INR) by counterparty, including:

- ICICI Securities
- Kotak Securities
- HDFC Securities
- Angel One
- Zerodha

### Asset Class Distribution
Analyzes trade volume across:

- Equity
- Derivatives
